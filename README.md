# Nico Buffer

A Geometry Dash Geode mod project targeting Geometry Dash 2.2081 on Android 64-bit.

The intended mod will provide configurable input buffering (0–30 frames) with per-game-mode controls. This repository currently contains the initial build scaffold; gameplay hooks and settings are being added incrementally.

## Build

GitHub Actions builds an Android 64-bit `.geode` package on every push. Open the **Actions** tab and download the **Android64 Geode** artifact from a successful run.
